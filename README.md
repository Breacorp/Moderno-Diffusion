# Moderno Diffusion - Suite de Generación de Imágenes Local
[![Website](https://img.shields.io/badge/Web-moderno.com.ar-blue)](https://moderno.com.ar)

### Moderno Diffusion es la suite de escritorio de Moderno Tech para ejecutar modelos de Inteligencia Artificial (Stable Diffusion) de manera 100% local en tu Mac o PC.

* **Privacidad Total:** Funciona de forma completamente local en tu equipo; ningún dato o imagen se envía a la nube.
* **Optimizado:** Aprovecha la aceleración por hardware de chips Apple Silicon (M1/M2/M3/M4) y GPUs dedicadas.
* **Instalación directa:** Sin comandos complejos ni configuraciones tediosas.

## Features
* Full data privacy - nothing is sent to the cloud ( unless you chose to upload an image )
* Clean and easy to use UI with one-click installer
* Image to image
* Supported models : - SD 1.x, SD 2.x, SD XL, Inpainting, ControlNet, LoRA
* Download models from the app
* In-painting
* Out-painting
* Generation history
* Upscaling images
* Multiple image sizes
* Optimized for M1/M2 Chips
* Runs locally on your computer
* Negative prompts
* Advanced prompt options
* ControlNet


## How to use 

1) Download and start the application

![image](https://user-images.githubusercontent.com/1890549/198916443-c6a2e40a-3d1e-4000-882d-993aa1941391.png)


2) Ingresa un prompt y genera tus imágenes con aceleración de hardware local.

Funciones incluidas:
* **Text to Image:** Generación a partir de descripciones en lenguaje natural.
* **Image to Image:** Modificación guiada por imágenes iniciales o bocetos.
* **Inpainting:** Reemplazo y edición de áreas específicas sobre la imagen.
* **ControlNet:** Control posicional y de estructura visual (OpenPose, Depth, LineArt).
* **Modelos Personalizados:** Soporte para importar checkpoints `.ckpt` y `.safetensors`.
